# Шаблон создания нового бота

Скопируйте эту директорию в `bots/bot_XX_имя` для добавления нового бота в систему.

### Рекомендуемая структура папки каждого бота:
```text
bot_XX_name/
├── handlers/          # Обработчики команд и сообщений (/start, кнопки)
├── keyboards/         # Кнопки и клавиатуры (Inline / Reply)
├── middlewares/       # Промежуточные слои (auth, logging)
├── main.py            # Точка запуска данного бота
└── config.py          # Конфигурация конкретного бота
```
