# Telegram Bots Ecosystem (Mesh Network)

Проект совместной разработки экосистемы из 5–15 Telegram-ботов с единым сценарием и общей базой данных/событий.

## Быстрый старт для участников команды

### 1. Клонирование репозитория
```bash
git clone https://github.com/atdqueeng13/tg-bots-ecosystem.git
cd tg-bots-ecosystem
```

### 2. Настройка переменных окружения
Создайте локальный файл `.env` на основе шаблона:
```bash
cp .env.example .env
```
Заполните ваши реальные токены ботов в `.env`.

### 3. Правило разработки (Ветки / Branches)
> **ВАЖНО:** Не коммитьте напрямую в ветку `main`! Всегда создавайте отдельную ветку под своего бота или задачу.

## Структура проекта

```text
tg-bots-ecosystem/
├── bots/                  # Папки конкретных ботов экосистемы
│   ├── bot_01_.../        # Первый бот сценария
│   ├── bot_02_.../        # Второй бот сценария
│   └── template/          # Шаблон для быстрого создания нового бота
├── shared/                # Общие модули (БД, модели, шина событий)
│   ├── db/                # Общие таблицы и подключение к БД
│   ├── events/            # Логика обмена сообщениями между ботами
│   └── utils/             # Общие вспомогательные функции
├── docs/                  # Документация и контекст для ИИ-ассистентов
│   ├── ARCHITECTURE.md    # Описание архитектуры и правила для ИИ
│   ├── SCENARIOS.md       # Пошаговый сценарий взаимодействия ботов
│   └── GIT_WORKFLOW.md    # Инструкция по работе с Git для команды
├── .env.example           # Шаблон конфигурации
└── .gitignore             # Игнорируемые файлы (защита токенов и БД)
```

---

## Документация для ИИ
Перед началом разработки скормите вашему ИИ-ассистенту файл `docs/ARCHITECTURE.md` и `docs/SCENARIOS.md`, чтобы он следовал единым стандартам кода и знал всю архитектуру системы.
